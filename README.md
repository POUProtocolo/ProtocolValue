ProtocolValue publishes reference values defined by smart-contract mechanisms. Internal protocol value is distinct from a tradable token price and does not imply redeemability, available liquidity, solvency, or investment return.
Publication rule
A catalog listing requires publicly reproducible on-chain evidence of a protocol-defined per-token/share/unit value. A contract address, theoretical formula, third-party API, or JSON file alone is not sufficient. Evidence must permit a reader to identify a specific block, contract, function/calldata, raw return, decimals, and reconstruction of the displayed unit value. Relevant proxies and implementations must be identified where applicable.
EOL, DEPRECATED, and SUNSET_ISOLATED_POOL records are excluded from the published catalog. Research records are not endorsements or approved listings. Market-price aggregators are not used to define internal value.
Public material versus production code
This repository contains public methodology, disclosure documents, and examples of site-exported research evidence records. It does not claim to contain the entire website application or its production infrastructure. See docs/evidence/README.md for evidence provenance and limits.
